# 🎲 MGO Tracker

🇬🇧 [English](https://github.com/Kevinr99089/Mgo-Tracker/blob/main/README.md) | 🇫🇷 [Français](https://github.com/Kevinr99089/Mgo-Tracker/blob/main/READMEfr.md)

Bienvenue sur **MGO Tracker**, une application web autonome et performante conçue pour vous aider à suivre facilement vos albums, cartes et échanges sur Monopoly Go.

Que vous jouiez sur un seul compte ou que vous gériez plusieurs joueurs, cet outil offre une solution fluide, rapide et sécurisée pour mettre à jour votre progression en ligne ou hors ligne.

[![MGO Tracker](https://img.shields.io/badge/Lancez_MGO_Tracker-Créez/gérez_vos_tableaux-2563eb?style=for-the-badge)](https://kevinr99089.github.io/Mgo-Tracker/)

---

## 📦 Versions Disponibles

Cet outil est décliné en deux variantes, que vous pouvez retrouver dans la section [Releases](../../releases) sous forme de fichiers HTML monolithiques uniques :

* **MGO Tracker (Complet)** : L'expérience complète incluant des arrière-plans dynamiques et animés (Fonctionnalité "Ambiance" avec Orbes Cosmiques, Cartes Flottantes, Cadres Néons, etc.).
* **MGO Tracker Lite** : Une version allégée et optimisée pour les performances et les appareils plus modestes, proposant un fond statique esthétique sans animations lourdes.

## ✨ Fonctionnalités

* **100% Hors Ligne & Privé** : Cet outil fonctionne de manière totalement autonome hors ligne. Vos données restent à 100% privées et exclusivement sur votre appareil. Il n'y a aucune base de données externe, aucun pistage (tracking) et aucune collecte de données. Toutes les informations sont sauvegardées localement dans votre navigateur (`LocalStorage`), avec la possibilité d'exporter votre progression dans un fichier de sauvegarde `.json` pour le recharger à tout moment.
* **Suivi Multi-Comptes** : Ajoutez, renommez et gérez plusieurs joueurs depuis la même interface. Réorganisez-les facilement grâce au glisser-déposer.
* **Statut des Cartes** : Marquez vos cartes comme manquantes, obtenues ou en double (jusqu'à 3 états par carte).
* **Gestion des Cartes Or** : Configurez facilement les cartes "Or" de la saison actuelle et gérez une liste de contrôle dédiée aux "Échanges Gold".
* **Partage et Importation de Tableaux** : Générez un lien unique et compressé pour partager votre tableau spécifique avec vos amis (via Discord, WhatsApp, etc.), leur permettant de l'importer directement dans leur propre tracker. *Note : Le lien de partage est une capture de votre tableau au moment où vous le créez — il ne se mettra pas à jour tout seul. Si vous faites des modifications par la suite et souhaitez que l'autre personne ait la dernière version, il vous suffit de partager un nouveau lien.*
* **Mode Impression** : Besoin d'une copie physique ? Utilisez la mise en page d'impression intégrée pour imprimer efficacement les tableaux des joueurs de votre choix.
* **Bilingue** : Détecte automatiquement la langue de votre navigateur pour basculer de manière transparente entre le français et l'anglais.

## 🚀 Comment l'utiliser

MGO Tracker étant construit comme un fichier HTML, aucune installation complexe n'est requise :

1.  **Version Web** : Cliquez simplement sur le badge ci-dessus pour visiter la page en ligne.
2.  **Version Locale** : Allez dans l'onglet **Releases**, téléchargez le fichier `.html` (Complet ou Lite), et double-cliquez dessus pour l'ouvrir dans n'importe quel navigateur web moderne. Aucune connexion internet n'est requise pour utiliser le fichier localement !

## 🛠️ Informations Techniques

* Créé entièrement en HTML, CSS et JavaScript Vanilla pur.
* Zéro dépendance, aucune base de données externe.
* Les versions disponibles dans les releases sont regroupé dans un seul fichier pour une portabilité maximale.
